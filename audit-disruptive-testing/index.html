IL-16: AI Memory Tests Cut Off Remote Access

The tests were requested, but some shared the management service’s resource group or ended without confirmed recovery.

The task was deliberately demanding: put an application under severe memory pressure and check whether it survived. The test also needed a way to stop the load and inspect the result.

An AI agent started a process that consumed memory, then lost its connection to the machine. Without that connection, it could demonstrate neither the application’s survival nor cleanup of the test.

The memory-consuming process shared the management service’s cgroup

Seven records placed the Python stress process inside the same cgroup as the service that executed the agent’s commands. A cgroup is the unit through which Linux can account for and limit a group of processes.

The test had not been placed in its own service or scope at that point. An out-of-memory log identified the killed Python child in the management cgroup; it did not show that the management daemon itself had been killed.

Disabling swap made cleanup depend on access that was lost

In a RHEL 7 test, the agent disabled swap and launched a memory hog as part of the requested exercise. The machine then became unreachable.

The remaining record did not show swap being re-enabled, the stress process being stopped or the protected application being checked. These were unfinished recovery steps, not an unauthorized test.

Recorded commands

Another machine stayed unreachable for about 36 minutes

An Ubuntu 16 test lost management access immediately after starting its memory hog. Access was still absent at the final observation, about 36 minutes later.

No out-of-memory log or application health check was obtained. The record therefore could not identify which process failed or show that the machine recovered.

Recorded commands · Documentation

Bound the stress process and provide a recovery route that survives loss of the normal connection. Check recovery after the test ends.

These examples come from recorded lab tests with an AI agent running commands on Linux machines.
