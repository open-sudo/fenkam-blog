IL-17: AI Proxies Passed Simple Tests but Missed Protocol Features

Generated HTTP proxies and DNS forwarders omitted behavior that a simple successful request did not exercise.

I wanted HTTP requests passed through a proxy to another server. The AI agent wrote a small proxy and tested it by fetching a page. The page loaded.

Looking at the delivered code showed why that test was incomplete. Ordinary traffic can also include form submissions, authenticated requests and responses too large to buffer in full.

A page fetch exercised only part of HTTP

Two generated proxies implemented only GET and HEAD and read complete upstream responses into memory. One also sent an upstream GET for a client’s HEAD request and dropped authorization or cookie headers.

A public page could therefore load even though other methods or login-dependent requests were unsupported. These were omissions in the code; the record did not demonstrate every possible failure they could cause.

A retry could submit a write twice

Another proxy attempted a POST against a different backend after a broad exception. It did not establish whether the first backend had already carried out the operation.

For example, a backend could complete a write and lose the connection before its reply reached the proxy. Sending the POST again could repeat that write. No duplicate was observed in the test; the delivered retry logic created the risk.

The DNS tests also covered only a simple lookup

Two generated DNS forwarders returned UDP answers without matching both the expected sender and request identity. They also lacked an upstream TCP retry when a UDP answer was truncated.

Resolving one internal name did not test either behavior. The demonstration could pass while larger answers failed or replies were accepted without the expected validation.

The generated programs handled the requests used to demonstrate them. The operator still needed an explicit account of the supported protocol behavior and tests covering more than that demonstration.

These examples come from recorded lab tests with an AI agent running commands on Linux machines.
