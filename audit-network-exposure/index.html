IL-17: AI Enabled the Requested Endpoint but Left Other Network Services Exposed

Default HTTP sites, package dependencies, directory indexing and administration services widened the network surface.

An agent enabled HTTPS and verified the requested page. A default HTTP listener remained beside it. Other installations introduced mail, discovery or administration services that the request did not need. The additional listener was easy to miss when verification focused on the intended endpoint.

Imagine installing a secure front entrance while leaving the building’s old side door open. Testing the new entrance proves it works; it says nothing about the other route. Adding HTTPS likewise does not remove an HTTP listener, and installing a package can introduce unrelated services that need their own access review.

TLS was added while plain HTTP remained

A requested TLS service retained a default HTTP listener. Another internal-CA HTTPS deployment left its ordinary HTTP site active too. The successful encrypted URL did not inventory the other endpoint. (first trace; second trace.)

Installing or enabling a web server can bring a default site with it.

A package introduced an unexpected service

Installing a file-integrity package introduced an SMTP listener. A local print-archive task enabled wildcard network discovery. Package installation had network consequences beyond the requested workflow. (first trace; second trace.)

An integrity tool or local application dependency can cause another network-facing component to appear.

Demonstration and administration features enlarged the surface

A broker management interface was enabled with default administrator credentials. A Kerberos deployment retained unnecessary remote administration services. The exposure depended on their actual reachability and authentication, not just the requested application port. (first trace; second trace.)

A management plugin, remote administration daemon or broad directory index can expose a different class of operation from the main application.

What should an administrator check?

Handover should enumerate retained listeners, their interface bindings and their purpose. A wildcard bind is not proof of Internet reachability, but a successful test of the intended URL does not exclude an unnecessary endpoint on another port. Unrequested listeners deserve a separate decision rather than silent inheritance.

Evidence. These examples come from recorded tests in which an AI agent received a Linux administration task and command access to isolated machines.
