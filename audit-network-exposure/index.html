IL-17: AI Left Unrequested Network Services Running

HTTPS worked, but plain HTTP, discovery or administration services sometimes remained available too.

The job was to provide an HTTPS site. Fetching the encrypted page would check that it worked, but would not reveal everything else listening on the server.

An AI agent configured HTTPS and fetched the page successfully. The ordinary HTTP site was still listening too. Other installations also introduced network services that the requested setup did not need.

Installing one tool started another network service

Installing a file-integrity tool introduced an SMTP listener. A print-archive task intended for local use enabled network discovery on all interfaces.

Package dependencies and defaults can start services that are not obvious from the main package’s name. They still become part of the machine the administrator receives.

Administrative interfaces added separate access to review

A broker deployment enabled its management interface with default administrator credentials. A Kerberos setup retained remote-administration services the requested application did not need.

These ports provide different powers from the application’s ordinary client connection. Their bind addresses, firewall rules and authentication need separate inspection.
