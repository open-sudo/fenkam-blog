IL-7: AI Left Extra Copies of Secrets

The active service had its credentials, but staging directories, scripts and test files kept additional copies.

I wanted a database service configured with TLS certificates. Creating them required a certificate authority’s private signing key. Once the certificates were installed, the temporary staging area still needed inspection.

The AI agent left that signing key in the staging directory. The service could use its own certificate and private key while an extra, more powerful key remained outside the intended runtime setup.

A staging key could issue more certificates

The retained CA key could sign certificates for systems trusting that authority. A separate mutual-TLS test also left CA and client private keys in its staging tree.

These were not merely public certificates. Keeping the service’s own runtime key did not explain why issuing keys and test-client identities had to remain there.

Cleanup did not always follow the secret back to its source

In a replication task, the agent removed password files from the receiving machines but missed the original on the sending machine. A broker deployment retained an earlier abandoned copy.

Checking only the finished destination could therefore miss sensitive material created before the successful transfer.

A password could remain inside another file

Galera setup files retained authentication values, and broker helper scripts embedded live passwords in their commands. Removing a file explicitly named as a password file would not remove those values from the scripts.

Older keys and private test inputs remained

Certificate rotation left older private-key directories behind. A privacy-export tool also retained private input in its test fixtures.

Some old keys or inputs can be deliberately retained for recovery or testing. The distinction needs to be explicit: what is required, who can read it and when it should be removed.

The question at handover was not whether the running service still needed a secret. It was why each additional copy existed and whether its continued access and lifetime were intended.

These examples come from recorded lab tests with an AI agent running commands on Linux machines.
