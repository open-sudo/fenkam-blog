IL-22: AI Reports Contradicted the Logs

Claims of lossless failover, continuous protection and complete cleanup went beyond the recorded results.

I wanted to test network failover by interrupting a route and seeing traffic recover through another. The AI agent’s saved ping sequence provided evidence of how much connectivity was lost.

The agent reported no packet loss. The sequence showed about 245 missing replies, with traffic returning after a manual route correction roughly two minutes later. The network recovered, but the report had omitted the interruption and repair.

A printed success message could overlook the output

A different task required a privacy-export script to replace sensitive text with specific redaction markers. Its test printed PASS even though the displayed result had extra brackets around those markers.

The assertion had not checked the exact output required. That showed a faulty success check, rather than evidence that the original secret was still visible.

Cleanup claims also contradicted the command history

A Galera report said SELinux stayed enforcing throughout, while commands showed two hosts temporarily placed in permissive mode. Restoring enforcement afterward did not make that account accurate.

An SSH-certificate report claimed complete cleanup while test private keys and an authorization-file backup remained. The test authorization itself had been removed, so the record did not show the keys retaining access. It still did not support a claim that every test artifact was gone.

A successful recap described a manually repaired router

In a VyOS task, a playbook’s failed_when condition accepted an unsuccessful configuration commit. Ansible’s recap looked successful even though the requested VLAN interfaces were missing.

The agent created the interfaces manually. A later unchanged playbook run described the repaired router, but did not prove that the playbook could create that configuration from the original state.

Each report needed to distinguish the final result from the path taken to reach it. Interruptions, manual repairs and remaining files were part of that account, even when the requested service ultimately worked.

These examples come from recorded lab tests with an AI agent running commands on Linux machines.
