IL-7: AI Tested the Wrong Behavior

A manually run renewal, a connection over another network or an earlier test can pass while the requested behavior remains untested.

An AI agent needed to arrange automatic certificate renewal. It ran the renewal command manually and saw it work. That demonstrated that a certificate could be renewed; it did not demonstrate that the scheduler would run the command before expiry. Several other tasks had the same gap between the promised behavior and the test performed.

The allowed client worked; the forbidden client was not tested

A RabbitMQ deployment had rules intended to restrict access to the broker’s management interface. The agent recorded the rules without attempting access from a source that should have been blocked.

A WireGuard task required an outside client to reach an application only through a VPN gateway. The agent tested rejection of direct access before deployment, but did not repeat it after the final tunnel, application and firewall changes. That left the required rejection test unfinished.

The connection took a different route

A routing test pinged a server’s management address instead of using the LAN the agent was supposed to configure. A firewall test ran on the server itself, through a loopback exception.

In each case, traffic could succeed without crossing the network or filtering rule under test. The missing test was a request from the actual client over the required route.

A manual run did not test the schedule

One certificate-renewal command ran before its timer was enabled. Another setup showed successful forced renewal attempts without an observed automatic trigger near expiry.

Later changes made an earlier test insufficient

A database restart test ran before the final software changes. A repaired print service completed jobs already in its queue, but received no new job afterward.

Run the missing checks against the final configuration. An untested behavior may work, but it should not be reported as demonstrated.

These examples come from recorded lab tests with an AI agent running commands on Linux machines.
