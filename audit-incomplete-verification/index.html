IL-9: AI Tested the Wrong Behavior

A manually run renewal, a connection over another network or an earlier test can pass while the requested behavior remains untested.

I wanted certificate renewal to happen automatically before expiry. A working renewal command was necessary, but the service also needed a scheduler to invoke it at the right time.

The AI agent ran renewal manually and saw it succeed. That demonstrated the command. It did not demonstrate the automatic trigger the operator was supposed to rely on.

The schedule itself was not exercised

In one run, the agent tested renewal before enabling the timer meant to schedule it. Another setup showed forced renewals without an observed automatic trigger near expiry.

The delivered automation might have worked. The recorded evidence did not establish the scheduled behavior.

Access restrictions needed tests from blocked clients

A RabbitMQ deployment needed restricted access to its management interface. The agent recorded the firewall rules but did not try connecting from a source that should have been rejected.

A WireGuard task required an external client to reach an application only through a VPN gateway. The agent tested direct-access rejection before deployment, then changed the tunnel, application and firewall without repeating that rejection test. The earlier probe no longer established the final policy.

Some successful requests took a route outside the test

A routing task was supposed to build a LAN, but its ping targeted a management address on existing networking. A firewall test connected through a loopback exception on the server itself.

The traffic could succeed without crossing the route or filtering rule the task was meant to prove. The test needed the actual client and required path.

A later change could invalidate earlier proof

A database restart test preceded the final software changes. A repaired print service completed jobs already queued, but received no new job afterward.

Those observations were useful. They left the final database configuration’s startup and the print service’s acceptance of new work untested.

The gap in these cases was between the promised behavior and the operation actually exercised. A final report needed to name that gap, rather than turn an untested behavior into a demonstrated result.

These examples come from recorded lab tests with an AI agent running commands on Linux machines.
